__ID Matching__ 

The complete-case samples from each dataset (as generated using the Phenotype Protocol: https://github.com/eviedoherty/PGC_SCZ_Cognition_Protocol/tree/main)  should be matched to available PGC Wave 2, 3 and/or 4 genotype data on Snellius, the Dutch National Supercomputer.  

__Sample size__: Each dataset should have >100 individuals after matching phenotype to genotype IDs. 

__Smaller datasets__ (<100): Datasets with <100 individuals will not be analysed in this iteration of the PGC SCZ – Cognition Subgroup analysis.  
However, you may still be able to contribute by combining several smaller datasets from the same cohort or ancestry. 

Please see the __Data Preparation__ section for more details.
