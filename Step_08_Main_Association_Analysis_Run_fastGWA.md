# Running GCTA fastGWA 

The association analysis (fastGWA) should be run using the per chromosome BGEN files containing dosage marker calls (as generated by __02_dosage_combine_per_chr.sh__ or __03_merge_all_dataset_chrs.sh__ (if datasets have been collapsed)).  

__Note__: Before running the association analysis, please ensure that FID and IID columns match across the phenotype file (.tsv), chromosome sample file (.sample), and GRM ID file (.id). For example, the .sample file may only contain IDs in a single column, when IDs should be present in column 1 and column 2. This can be rectified using the following code on your .sample files: 

```bash
for chr in {1..22}; do

    awk 'BEGIN{OFS="\t"}
         NR==1{print "ID_1","ID_2","missing","sex"; next}
         NR==2{print "0","0","0","D"; next}
         {print $1,$1,$2,$3}' \
         chr${chr}_merged.sample > chr${chr}_merged_fixed.sample

done
```

## Genotype Index File 

In fastGWA, each BGEN file must have a corresponding BGEN index file (.bgi). This can be generated in bgenix via Snellius using the following code:  

__Load and activate bgenix__

```bash
module load 2023
module load Anaconda3/2023.07-2
conda create -n bgen -c bioconda -c conda-forge bgenix
conda activate bgen
```

__Find the bgenix path__ 

```bash
Which bgenix
```

__Run from the path and generate index file to accompany .bgen file__


```bash
for chr in {1..22}; do

    ~/.conda/envs/bgen/bin/bgenix \
        -g /path/to/your/bgen_files/chr${chr}_merged.bgen \
        -index
done
```

__Note__: bgenix is not available as a module on Snellius, hence the use of a conda environment.    

 

## Phenotype File 

Phenotype files should be in a tab separated format (.tsv). There should be three columns; FID, IID and the phenotype of interest which in this case is g.  

FID and IID columns should match those in the chromosome sample (.sample), and GRM ID (.id) files. 


## Covariates 

Each genetic analysis should be covaried for age, sex and a subset of the principal components derived in each cohort using the PCA (see Principal Component Estimation). The first four PCs should be included as covariates in all association analyses, alongside any additional PCs that are nominally significantly associated with the *g*-factor phenotype (P < 0.05). 

FastGWA requires continuous (--qcovar) and categorical (--covar) variables to be divided into separate files. Please ensure that covariate data is accompanied by identical FIDs and IIDs that match the .sample file belonging to the genotype files. 

Covariates Files 

__Note__: When generating covariates files, please ensures there are no NAs in the FID/IID columns as this will flag the following error:  

Error: duplicated FID+IID in the covariate file.  

This may occur if individuals have phenotype data and no genotype data.  


## Running fastGWA association analysis

```bash
/path/to/gcta-1.95.3-linux-x86_64/squashfs-root/usr/bin/gcta64 \ 
  --bgen /path/to/your/bgen_files/chr1_merged.bgen \ 
  --sample /path/to/your/bgen_sample_files/chr1_merged_fixed.sample \ 
  --grm-sparse /path/to/your/sparse_grm/grm_fastgwa_sparse \ 
  --fastGWA-mlm \ 
  --pheno /path/to/your/phenotype_file/dataset_pheno_g.tsv \ 
  --qcovar /path/to/your/qcovar_file/dataset_qcovars.tsv \ 
  --covar /path/to/your/covar_file/dataset_covars.tsv \ 
  --thread-num 10 \ 
  --out fastGWA_c1_dataset
```

__Note__: This can be looped for efficiency.
