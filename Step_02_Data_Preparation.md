# __Data Preparation__ 

Datasets from the same data site which have a similar composition i.e. several of the same cognitive measures, with less than 100 samples should be collapsed and analysed together as a single unit (as per Nievergelt et al., 2024).  

Before collapsing similar datasets, please ensure that the imputation methods are the same across datasets (differing imputation panels are acceptable between sites but not within sites). Note that after collapsing datasets, a ‘g’ factor must be derived for the combined dataset before proceeding (Phenotype Protocol: https://github.com/eviedoherty/PGC_SCZ_Cognition_Protocol/tree/main).  

If collapsing is not an option or you are unsure, please contact e.doherty37@universityofgalway.ie for guidance.
